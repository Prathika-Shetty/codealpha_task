Student Grade Tracker

Project Description

Student Grade Tracker is a Java-based project that manages student marks and generates a simple performance report.

Features

- Enter details of multiple students
- Enter marks for Kannada, Maths, and English
- Calculate average marks
- Display highest and lowest marks
- Identify the class topper
- Handle multiple toppers when students have the same highest average
- Identify failed students and the subjects they did not clear

Technologies Used

- Java
- ArrayList
- Object-Oriented Programming

Project Structure

- "Student.java" – Stores student details and marks
- "StudentGradeTracker.java" – Main program and grade tracking logic

How to Run

1. Open the project in VS Code.
2. Compile the Java files.
3. Run "StudentGradeTracker.java".
4. Enter the student details and marks when prompted.
