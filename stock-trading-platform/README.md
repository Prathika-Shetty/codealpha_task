Stock Trading Platform

Project Description

Stock Trading Platform is a Java-based project that simulates basic stock trading operations. Users can view available stocks, buy stocks, sell stocks, and view their transactions.

Features

- Display available stocks
- Add and manage users
- Buy stocks
- Sell stocks
- Track stock quantity
- Record transactions
- Display trading information

Technologies Used

- Java
- Object-Oriented Programming

Files

- "Stock.java" – Stores stock details such as symbol, name, price, and quantity.
- "User.java" – Manages user information.
- "Transaction.java" – Stores transaction details.
- "StockTradingPlatform.java" – Main program that runs the stock trading platform.

How to Run

Compile the Java files and run the main class:

javac *.java
java StockTradingPlatform
